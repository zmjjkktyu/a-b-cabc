# Tips18

Rootless Theos/Logos tweak for iOS 16.1+ that adds an iOS 18-inspired new-feature bulb UI to Apple Tips.

## Build

Install Theos and an iPhoneOS SDK, then run:

    make package THEOS_PACKAGE_SCHEME=rootless

The resulting .deb can be installed with a rootless package manager such as Sileo/Zebra.

## Notes

This is a third-party visual recreation. It does not enable actual iOS 18 system features or change the device OS version.
